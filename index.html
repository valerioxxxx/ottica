☁ Salvataggio automatico su GitHub

Con questo collegamento la rubrica si salva da sola su internet a ogni modifica: non serve più scaricare copie a mano, e gli stessi dati si vedono da tutti i computer collegati.

Importante: il repository dei dati deve essere PRIVATO. Contiene dati sanitari dei clienti: se fosse pubblico, chiunque su internet potrebbe leggerli.
  1. Su github.com crea un repository nuovo, per esempio rubrica-dati, e scegli Private.
  2. Vai su Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. In Repository access scegli Only select repositories e seleziona solo rubrica-dati. In Permissions → Repository permissions metti Contents: Read and write. Imposta una scadenza lunga (es. 1 anno).
  4. Copia il token (inizia con github_pat_) e incollalo qui sotto.

Il token resta su questo computer e non viene mai scritto nella rubrica. Chi usa questo computer può leggerlo: usalo solo su computer di cui ti fidi.
